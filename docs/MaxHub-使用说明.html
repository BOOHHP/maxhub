01 / 首次

第一次使用，只需四步

全程需要公司内网、Windows 和飞书账号。每个要使用的 Max 年份都要安装一次 Connector。

下载并启动 Agent

打开内网工具市场，点击“下载最新版”，运行下载到本机的 MaxHubAgent EXE。它会自动扫描 3ds Max 2019–2026。

结果：显示本机 Max

飞书扫码登录

在“账号”页点击“飞书扫码登录”，在浏览器中用飞书 App 授权。回到 Agent 后确认显示“登录有效，自动续期中”。

结果：账号已连接

安装 Connector

打开“Connector 管理”，为单个 Max 点击安装，或使用“全部安装”。多个 Max 年份需要分别安装。

结果：各年份已安装

重启 3ds Max

工具中心通常随 Max 启动自动打开；也可以在“宏 / 工具栏”中搜索 MaxHub 手动打开。

结果：Agent 已连接
关键：关闭 Agent 主窗口只会隐藏到托盘。让 Agent 保持运行，3ds Max 内的工具中心才能联网、安装和更新。

发现与安装

选中工具，检查版本、适用 Max 范围与说明，再点击“安装选中”。普通脚本可立即运行；Startup 工具需重启 Max。

运行

进入“已安装”，点击“运行选中”，或直接双击工具。脚本由当前 3ds Max 执行。

更新

进入“更新”，处理单个工具或点击“全部更新”。涉及 Startup 文件时，更新后重启 Max。

卸载与回滚

在“已安装”中选择对应操作。人工修改过的文件会被保留并报告冲突，避免误删。

环境与诊断

查看 Agent、当前 Max、已安装与可更新数量。遇到问题先“重新检查”，再“复制摘要”。

工具反馈

在前三页选中工具后点击“反馈”。内容会发给最新版本上传者并抄送管理员。

03 / AGENT

Agent 是后台中枢

它负责身份、下载验签、安装账本、Connector 和本机工具。退出 Agent 后，Max 内工具中心将不可用。

账号

  • 飞书登录 / 退出
  • 查看服务器与登录状态
  • 检查 Agent 更新
  • 查看中文更新日志

Connector 管理

  • 重新检测本机 Max
  • 单个或全部安装 Connector
  • 更新 / 同步 Connector
  • 从 Agent 直接“打开 Max”

工具管理

  • 本机工具：查看与卸载
  • 市场：选择 Max 年份后安装
  • 上传脚本：自动识别并提交审核

平台反馈

MaxHub 平台本身有问题时，在 Agent“反馈”页提交 5–2000 字纯文本，内容会送达平台负责人。

04 / 角色

按角色使用发布与管理功能

所有人都可浏览；上传、审核和治理需要管理员预先分配角色。

  • 安装与运行

  • 通过 / 退回

  • 撤回与统计

  • 成员角色
  • Agent / Connector
  • 反馈补发

推荐：脚本直传

选择 `.ms`、`.mcr` 或 `.py`，系统自动识别名称与描述。确认版本号、Max 兼容范围和更新说明后提交审核。

高级：ZIP 工具包

ZIP 根目录需包含 `manifest.json` 与 `payload/`。适合多文件或需要精确安装位置的工具。

当前不自动管理第三方原生 `.dlu`、`.dlm`、`.dll` 插件；不要把这类文件当作普通脚本包发布。
05 / 排障

故障速查

先检查 Agent，再检查 Connector，最后复制诊断摘要反馈。

3ds Max 内显示“Agent 未响应”
确认 Windows 托盘中有 MaxHub Agent；若没有则启动它。确认已登录且服务器地址正确，再到工具中心“环境”页点击“重新检查”。
MaxHub 面板没有出现
确认对应 Max 年份已安装 Connector；安装或更新后重启 Max；在“宏 / 工具栏”中搜索 MaxHub。仍异常时复制“诊断”摘要并提交平台反馈。
看不到工具或安装按钮不可用
确认 Agent 正在运行并已登录、公司服务器可访问、工具支持当前 Max 年份，然后刷新列表。
安装成功但工具没有生效
普通脚本到“已安装”页双击运行；Startup 工具需重启 Max；MacroScript 请在 Max 的宏或自定义工具栏中寻找入口。
卸载后仍有文件
文件很可能在安装后被人工修改。MaxHub 会保留它并报告冲突，不会强制删除；确认用途后再人工处理。
Agent、Connector 或工具如何更新
Agent：账号页“检查更新”；Connector：Connector 管理页更新或同步后重启 Max；工具：Max 工具中心“更新”页。
服务器暂时不可访问
Agent 1.0.22 仍可启动并保留凭据，但登录、市场、安装和反馈等联网功能暂不可用。服务器恢复后重新检查或重启 Agent。
