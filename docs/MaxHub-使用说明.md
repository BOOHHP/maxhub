# MaxHub 使用说明

> 面向公司内部 3ds Max 美术、TA、脚本发布者与平台管理员  
> 适用版本：MaxHub Agent 1.0.22、Connector 1.5.7  
> 文档日期：2026-08-21

## 一分钟了解 MaxHub

MaxHub 是公司内部的 3ds Max 脚本管理与分发平台。它把原来通过群文件、共享目录和手工复制脚本的流程，整合成“浏览、安装、运行、更新、卸载、反馈”一套流程。

你会接触三个入口：

| 入口 | 作用 | 谁会用 |
| --- | --- | --- |
| MaxHub Agent | 登录、检测本机 Max、安装 Connector、管理工具、上传脚本、自更新 | 所有人 |
| MaxHub 工具中心 | 在 3ds Max 内发现、安装、运行、更新、卸载和反馈 | 3ds Max 使用者 |
| Web Portal | 浏览工具市场、发布工具、审核与平台管理 | 所有人 / 发布者 / 管理员 |

工作关系：

```text
Web 工具市场 / 公司服务器
            ↓
    MaxHub Agent（Windows 托盘）
            ↓
MaxHub 工具中心（3ds Max 内）
            ↓
       已安装的脚本工具
```

生产入口（需处于公司内网）：[http://10.2.13.8:5100/index.html](http://10.2.13.8:5100)

## 第一次使用

### 1. 下载并启动 MaxHub Agent

1. 在公司内网打开 MaxHub 工具市场。
2. 点击页面顶部的“下载最新版”。
3. 运行下载到本机的 `MaxHubAgent-版本号-win-x64.exe`。
4. Agent 会自动扫描本机已安装的 3ds Max 2019–2026。

提示：Agent 是单实例程序。重复启动不会打开第二个进程，而会唤起已经运行的窗口。

### 2. 使用飞书登录

1. 在 Agent 的“账号”页点击“飞书扫码登录”。
2. 浏览器打开授权页面后，使用飞书 App 扫码。
3. 授权成功后回到 Agent，确认页面显示姓名与“登录有效，自动续期中”。

MaxHub 不保存飞书密码。退出登录后，3ds Max 内的工具中心将无法访问需要身份验证的功能。

### 3. 为本机 Max 安装 Connector

1. 打开 Agent 左侧的“Connector 管理”。
2. 检查 Agent 识别出的每个 3ds Max 版本和安装目录。
3. 点击单个版本右侧的安装按钮，或点击“全部安装”。
4. 安装完成后，重启对应版本的 3ds Max。

Connector 会分别安装到每个 Max 年份的用户目录。同一台电脑装有多个 Max 版本时，需要为每个要使用的版本安装一次。

### 4. 打开 MaxHub 工具中心

重启 3ds Max 后，MaxHub 工具中心通常会自动打开。也可以在 3ds Max 的“宏 / 工具栏”中找到 `MaxHub`，手动打开面板。

看到以下状态即可开始使用：

- “Agent：已连接”
- “当前：3ds Max 20xx”与实际年份一致
- 工具列表可以正常刷新

## 日常使用

### 发现并安装工具

1. 保持 MaxHub Agent 在 Windows 托盘运行。
2. 在 3ds Max 中打开“MaxHub 工具中心”。
3. 进入“发现”，浏览按分类排列的工具。
4. 选中工具，先查看名称、版本、适用 Max 范围和工具说明。
5. 点击“安装选中”，等待进度完成。

普通脚本工具安装后可以立即运行；Startup 类型工具需要重启 3ds Max 才会生效。

### 运行工具

1. 进入“已安装”。
2. 选中工具后点击“运行选中”，或直接双击工具。

MaxScript / MacroScript 与 Python 脚本由当前 3ds Max 执行。如果工具本身有独立面板，它会在运行后打开。

### 更新工具

1. 进入“更新”。
2. 点击“更新选中”更新单个工具，或点击“全部更新”。
3. 等待全部任务完成。

如果更新涉及 Startup 文件，请重启 3ds Max。

### 卸载与回滚

- 卸载：在“已安装”中选中工具，点击“卸载选中”并确认。
- 回滚：选中工具，点击“回滚上一版”并确认。

MaxHub 只处理安装账本记录且内容匹配的文件。如果文件安装后被人工修改，卸载时会保留该文件并提示冲突，避免误删用户内容。

### 提交工具反馈

在“发现”“已安装”或“更新”页中选中工具，点击“反馈”，填写 5–2000 字后提交。工具反馈会发送给该工具最新版本的上传者，并抄送平台管理员。

如果是 MaxHub 平台本身的问题，请打开 Agent 左侧的“反馈”页提交。平台反馈会发送给平台负责人。

## MaxHub Agent 使用说明

### 账号

- 登录或退出飞书账号。
- 查看当前用户名、员工 ID、服务器地址与登录状态。
- 手动检查 Agent 更新；确认后会下载、校验、替换并重启新版。
- 查看内置中文更新日志。

### Connector 管理

- 查看自动检测到的 3ds Max 版本。
- 为单个版本安装、更新或同步 Connector。
- 一键为所有已检测版本安装 Connector。
- 直接点击“打开 Max”启动对应版本的 3ds Max。

### 工具管理

“本机工具”用于查看与卸载已经安装到本机的工具；“市场”用于选择目标 Max 年份并安装已审核工具；“上传脚本”用于发布 `.ms` 或 `.py` 脚本。

### 托盘行为

- 关闭 Agent 主窗口只是隐藏到 Windows 托盘，Agent 仍在运行。
- 需要让 3ds Max 工具中心保持可用时，不要退出 Agent。
- 只有在托盘菜单中选择“退出程序”，才会真正停止 Agent 和本地连接服务。

## 发布工具（发布者）

发布者可以从 Web Portal 的“发布工具”页，或 Agent 的“工具管理 → 上传脚本”提交工具。

### 推荐：脚本直传

适用于 `.ms`、`.mcr`、`.py` 脚本。

1. 使用飞书扫码登录。
2. 选择“脚本直传（自动识别）”。
3. 选择本地脚本。
4. 检查系统自动识别的名称和描述，必要时修改。
5. 填写版本号、兼容 Max 范围和更新说明。
6. 点击“提交审核”。
7. 在“我的提交”查看状态：待审核、已发布、已退回或已撤回。

建议脚本头部提供结构化注释（如 `@name`、`@description`），这样自动识别结果更准确。

### ZIP 工具包

适用于包含多文件或需要精确安装位置的工具。ZIP 根目录必须包含 `manifest.json` 与 `payload/`，并符合 MaxHub 协议。

当前自动管理的目标包括：

- 用户脚本目录 `scripts`
- 用户宏目录 `usermacros`
- 用户启动脚本目录 `scripts/startup`

当前不自动管理第三方原生 `.dlu`、`.dlm`、`.dll` 插件，也不接受任意绝对路径或越级路径。

## 审核与管理

### 审核者

登录后台管理后，可以：

- 在“审核队列”通过或退回提交。
- 在“版本管理”查看签名、频道、提交人和审核人。
- 编辑已发布工具的名称、描述、兼容范围等元数据。
- 撤回已发布版本；撤回后该版本会立即从索引和下载中隐藏。
- 查看使用统计和用户反馈。

### 管理员

管理员额外可以：

- 在“成员角色”分配管理员、审核者和发布者角色。
- 上传并注册 Connector 制品。
- 登记 Agent 新版本、下载地址和 SHA-256。
- 对投递失败或部分失败的反馈执行补发。

系统不允许管理员取消自己的管理员角色，以避免无人可管理的平台锁死状态。

## 故障速查

### 3ds Max 内显示“Agent 未响应”

1. 查看 Windows 右下角托盘是否有 MaxHub Agent。
2. 若没有，启动 MaxHub Agent。
3. 打开 Agent，确认已经登录且服务器地址正确。
4. 回到 MaxHub 工具中心，进入“环境”并点击“重新检查”。

### MaxHub 面板没有出现

1. 确认 Agent 的“Connector 管理”中，该 Max 年份显示已安装。
2. 安装或更新 Connector 后重启 3ds Max。
3. 在 3ds Max 的“宏 / 工具栏”中搜索 `MaxHub`。
4. 仍无法打开时，在工具中心“诊断”页复制摘要并提交平台反馈。

### 看不到工具或安装按钮不可用

- 确认 Agent 正在运行并已登录。
- 确认公司服务器可访问。
- 确认工具支持当前 3ds Max 年份。
- 点击“刷新列表”或在“环境”页重新检查。

### 安装成功但工具没有生效

- 普通脚本：到“已安装”页双击运行。
- Startup 工具：重启 3ds Max。
- MacroScript：在 3ds Max 的宏或自定义工具栏中查找工具入口。

### 卸载后仍有文件

这通常表示文件在安装后被修改。MaxHub 会保留被修改的文件并报告冲突，不会强制删除。请先确认文件用途，再由熟悉该工具的人手工处理。

### Agent 或工具需要更新

- Agent：打开“账号”页，点击“检查更新”。
- Connector：打开“Connector 管理”，对对应 Max 年份执行更新或同步，然后重启 Max。
- 工具：在 3ds Max 工具中心的“更新”页处理。

### 服务器暂时不可访问

Agent 1.0.22 在服务器不可达时仍可启动并保留登录凭据，但登录、市场、安装和反馈等联网功能会暂时不可用。服务器恢复后重新检查或重启 Agent。

## 支持范围与注意事项

- 平台声明支持 3ds Max 2019–2026，当前 Max 2025 已完成真实使用验证；完整年份真机矩阵仍在持续补齐。
- 当前重点支持 MaxScript、MacroScript 与 Python 脚本型工具。
- 安装包会执行 SHA-256 与 ECDSA 签名校验；校验失败不会写入 Max 目录。
- Connector 只通过本机 `127.0.0.1` 与 Agent 通信，不直接下载或解压工具包。
- 工具与平台反馈为纯文本，不自动采集场景内容或用户文件路径。
