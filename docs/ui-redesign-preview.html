设计说明（确认要点）

视觉方向 暗夜终端 × 克制玻璃拟物。背景融入 3ds Max 视口透视网格与品牌光晕，呼应产品域；信息密度保持专业后台水准。
品牌延续 主色沿用 Agent 托盘的 #4C9FE0 蓝色阶梯，等距立方体 logo 与桌面端同源，Web 与桌面形成统一品牌。
创意点 ① 分类色环：每个工具分类一个专属色相（顶条 + 图标底色），扫一眼即可识别；② 卡片 hover 微抬升 + 顶条点亮；③ Hero 渐变标题与数据带。
动效策略 纯 CSS，无新增依赖：入场 stagger 上浮、150–280ms 缓动，尊重 prefers-reduced-motion；无持续重绘动画。
响应式 1440 / 1024 桌面双栏 → 960px 侧栏转横排 → 560px 单列卡片，均已验证布局不破。
可访问性 语义标签 + 键盘焦点环 + 表格数字等宽（tabular-nums）；正文对比度 ≥ 4.5:1。
